# Script execution
As the following order:
* Run the initializing database script <a href="https://github.com/sameh-abdullah/SQL-Data-Transformation-HR-/blob/main/Script/initializing%20database%20and%20schemas">Initializing Script</a>.
* Run the data ingestion to the bronze layer<a href="https://github.com/sameh-abdullah/SQL-Data-Transformation-HR-/blob/main/Script/Bronze%20layer/ddl%20and%20ingestion%20bronze%20layer"> DDL and Ingestion script</a>.
* Run the table creation script(silver layer) <a href="https://github.com/sameh-abdullah/SQL-Data-Transformation-HR-/blob/main/Script/Silver%20layer/create%20table%20(ddl%20silver)"> DDL silver Script</a>.
* Run the Data Transformation script <a href="https://github.com/sameh-abdullah/SQL-Data-Transformation-HR-/blob/main/Script/Silver%20layer/Data%20transformation%20script"> Transformation Script</a>.
* Run the <a href="https://github.com/sameh-abdullah/SQL-Data-Transformation-HR-/tree/main/Test">Test</a> and Qurey statements.
